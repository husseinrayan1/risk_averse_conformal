# Risk-Averse Conformal Prediction

This repository implements extensions of Risk-Averse Calibration (RAC) for
distribution-free decision making under uncertainty.

## Contributions
- Group-Conditional Risk-Averse Calibration (Fairness & Safety)
- Conceptual extension to sequential / online decision making

## Background
We build on:
"Decision-Theoretic Foundations for Conformal Prediction:
Optimal Uncertainty Quantification for Risk-Averse Agents"

## Repository Structure
- src/rac: offline RAC and group-conditional extensions
- experiments: synthetic evaluation
- report_notes: report-aligned explanations

## Status
Core group-conditional RAC implemented.
Sequential extension: conceptual.
